Where Could The Loop Grow?

This is a screening, not a plan. These are corridors worth a closer look. Nobody has checked that a path would fit.

The first page shows who lives far from the Loop. This one asks what would change that. The Loop is built along washes, so I tested every named wash in the area, plus every existing paved bike path that is not part of the Loop: … corridors in all. Each one is scored as if it were Loop, by counting the residents it would bring within the ride-time limit.

    How to read this

    • Candidates: every named wash in OpenStreetMap inside the study area, leaving out the parts that already have the Loop within … m, and every named paved bike path of … miles or more that is not in the Loop. Names are as OpenStreetMap has them.
    • Scoring: the candidate is treated as part of the Loop, and the count is the residents whose ride drops from over the limit to within it. An existing path is entered at its real junctions.
    • Entrances are generous: a path that does not exist yet is assumed reachable from any public street or path within … m of it. A real path would have fewer ways on, so the true numbers would be lower.
    • Nothing here says a path can be built: some washes have no room for one, and some run through private land. “Existing path” comes from how OpenStreetMap tags it; I have not checked the surface or condition of each one.
    • Built together: segments are added one at a time and a resident is counted once, however many segments reach them. By residents per new mile, an existing path costs no new miles and goes first, and a step has to add at least 2,000 residents to count.
    • Same ride times as the first page: shortest legal route at 10 mph, with traffic not counted. The sources and the rest of the method are listed there.
